  • Toast 消息 - 滑入滑出
  • 打字效果 - 模拟 AI 输入

  • 复选框 - 勾选动画
  • 开关 - 滑动切换
  • 下拉选择 - 填充高亮
  • 扫描波纹 - 整体扫描效果

  • 加载指示器 - 滑动进度条
  • 按钮状态 - 加载/成功/禁用
  • 折叠面板 - 展开/收起
  • 标签系统 - 添加/删除动画

使用说明

这些 Playground 页面包含了 AI Former 插件所有交互动效的独立 Demo。每个动效都可以通过控制按钮单独触发和测试，方便调整样式参数。在实际开发中，可以直接复制相关 CSS 和 JavaScript 代码到项目中使用。
