# AI Former - 智能表单填充助手

让表单填写变得轻松愉快！AI Former是一款革新性的Chrome浏览器插件，它将先进的AI技术与便捷的表单填写体验完美结合，帮助您告别繁琐的手动填写。

## 🌟 核心优势

- **智能高效**：通过自然语言描述，一键完成复杂表单填写
- **隐私优先**：支持本地模型运行，确保数据安全不外传
- **灵活便捷**：Chrome侧边栏模式，随时待命，即开即用
- **广泛兼容**：支持多种主流AI模型，满足不同场景需求

## 🚀 应用场景

- **求职申请**：快速填写各类招聘网站的申请表单
- **账号注册**：轻松完成网站注册、会员申请等信息填写
- **调查问卷**：智能理解并填写各类调查表单
- **信息采集**：高效处理数据收集、信息录入等任务

## 💡 主要功能

### 1. 多模型支持
- 本地Ollama模型：自动识别可用模型，保护隐私
- 通义千问API：接入阿里云百炼平台，提供稳定服务
- 更多模型支持：OpenAI、智谱AI、DeepSeek等

### 2. 智能表单识别
- 全面识别：支持常规表单、iframe内元素、contenteditable组件
- 可视化反馈：智能高亮显示已识别的表单元素
- 深度解析：准确理解表单结构和字段含义

### 3. 便捷操作体验
- 侧边栏模式：无需切换窗口，随时操作
- 快捷键支持：Ctrl+Enter快速识别填充
- 智能标签：高效管理和调用补充信息

## 🔧 使用指南

1. **安装配置**
   - Chrome扩展程序页面开启开发者模式
   - 加载已解压的扩展程序，选择插件文件夹
   - 配置所需的AI模型和相关参数

2. **日常使用**
   - 点击浏览器工具栏图标或右键菜单打开侧边栏
   - 输入自然语言描述您的需求
   - 一键完成表单识别和智能填充

## 🛡️ 隐私保护

我们始终将用户隐私放在首位：
- 支持本地模型运行，数据完全在本地处理
- 不收集、不存储任何用户表单数据
- API密钥严格保存在本地，不上传云端

## ⚠️ 使用须知

- Ollama模型需要本地运行Ollama服务
- 通义千问API需要有效的API密钥，详见[阿里云灵积平台](https://help.aliyun.com/zh/model-studio/billing-for-model-studio)
- Chrome侧边栏功能需要114或更高版本
- 部分网站可能因安全限制无法完全支持
